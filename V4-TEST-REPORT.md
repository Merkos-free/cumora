# мягко. — проверка версии 4

Область изменений: только тестовая ветка `myagko-preview`. Основная ветка проекта не менялась.

## Исправление

В предыдущем варианте первая игрушка лишь слегка смещалась, а полноценная закреплённая сцена находилась ниже. Теперь сама первая секция является сценой: фотография движется до прокрутки, а первые 150 пикселей прокрутки изменяют её положение, поворот и масштаб. Отдельные вложенные элементы отвечают за постоянное покачивание, прокрутку и реакцию на нажатие, поэтому их CSS transform не перезаписывают друг друга.

Удалена повторная закреплённая сцена перед каталогом. На первом экране появились переключение персонажа, три главы, изменение фона и индикатор продвижения. Кнопка остановки движения доступна в закреплённой шапке. Увеличены мобильные элементы управления и подписи. Исправлен белый прямоугольник вокруг поворачивающихся JPEG. Для короткого горизонтального экрана отключено закрепление секции, чтобы элементы оставались достижимыми обычной прокруткой.

## Границы проверки

Это локальные проверки в Chromium с мобильным размером окна и эмуляцией касаний, НЕ проверка на физическом iPhone и НЕ Safari/WebKit. Среда блокирует внешние запросы браузера. Для проверки композиции использован явно обозначенный локальный JPEG-заменитель; он НЕ включён в опубликованный магазин. При тесте сохранения использован отдельный in-memory Storage test double, поэтому нативное хранилище Safari этим тестом не подтверждается. В проверках загрузчика fetch получает известные локальные данные, а SHA-256 в about:blank вычисляется через hashlib; код загрузчика не изменён. Внешний HTTP-адрес из браузера этой среды не открыт.

В магазине остаются исходные внешние фотографии и модели Jellycat. Наличие доступа к их CDN зависит от сети посетителя. При ошибке основной фотографии выводится объяснение. Реальная оплата, доставка и отправка заказов отсутствуют. Это дизайн-концепт, не действующий магазин.

SHA-256 полной проверенной HTML-версии перед упаковкой:
`363c01749e55b4a90ee77e1e7e862cf2e9798b5a29d514d274648537b37818fb`

Загрузчик проверяет SHA-256 исходного содержимого и итоговой обновлённой версии перед отображением. Для проверки свежего результата используйте ссылку на конкретный commit, а не закэшированный адрес ветки.
